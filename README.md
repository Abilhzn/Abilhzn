### Practical Philosophy
> *"For a data engineer, the code is the warehouse. While others focus on the frontend, I focus on the integrity, flow, and validation of the data itself."*

- **Git Flow:** I maintain a clean branch management strategy for every project.
- **Backend-First:** Most of my project outputs are stored and managed via **Supabase** or external **PostgreSQL** instances.
